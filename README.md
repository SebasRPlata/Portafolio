# Portafolio de Desarrollo de Software | Sebastian Taype

Bienvenido a mi repositorio centralizado de proyectos. Aquí reúno soluciones prácticas enfocadas en automatización de procesos administrativos, gestión de activos tecnológicos y desarrollo de aplicaciones de escritorio con **Python**.

---

## Proyectos Incluidos

### 1. [Sistema de Inventario y Auditoría de Activos IT](./Inventario-IT-Desktop)
Aplicación de escritorio para el control, seguimiento y auditoría de equipos y activos tecnológicos.
* **Tecnologías:** Python, CustomTkinter, SQL / MySQL.
* **Características principales:**
  * Registro y consulta estructurada de hardware y periféricos.
  * Interfaz gráfica moderna y orientada a la gestión administrativa.
  * Trazabilidad para auditorías internas de soporte técnico.

### 2. [Generador Automatizado de Evidencias de Facturación](./Generador-evidencias)
Herramienta diseñada para optimizar el flujo de trabajo administrativo mediante la generación automática de reportes de respaldo en formato PDF.
* **Tecnologías:** Python, automatización de documentos PDF.
* **Características principales:**
  * Estandarización y compilación rápida de evidencias documentales.
  * Reducción de tiempos operativos en tareas repetitivas de facturación.
